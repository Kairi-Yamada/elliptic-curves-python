# elliptic-curves-python

卒業研究で学んだ楕円曲線の加法を、Pythonで実装した学習用プロジェクトです。
素数体上の楕円曲線について、点の加法・逆元・整数倍を計算できます。

## 対象とする楕円曲線

素数 $p \ge 5$ に対して、有限体 $\mathbb{F}_p$ 上の次の形の楕円曲線を扱います。

$$
y^2 = x^3 + Ax + B
$$

係数は $A,B\in\mathbb{F}_p$ とし、次の非特異性の条件を満たすものとします。

$$
4A^3 + 27B^2 \not\equiv 0 \pmod p
$$

曲線上の有限点を整数のタプル `(x, y)` で表し、無限遠点 `O` を `None` で表します。
係数と座標は、`p` で割った余りにより `0` から `p - 1` の範囲に正規化します。

## 動作環境

- Python 3.8以上
- 動作確認環境：Python 3.14.6
- 標準ライブラリのみを使用し、追加ライブラリのインストールは不要です。

## 使用例

各ファイルを同じフォルダーに置き、ターミナルでそのフォルダーへ移動して、Pythonを起動します。

```shell
python
```

本体はインポートして利用する構成です。起動したPythonで、次のコードを実行できます。

```python
from Elliptic_Curve_over_Fp import EllipticCurve, O

# F_17 上の曲線 y^2 = x^3 + 2x + 2
E = EllipticCurve(A=2, B=2, p=17)
P = E.point(5, 1)
Q = E.point(6, 3)

print(E.is_on_curve(P))         # True
print(E.add(P, Q))              # (10, 6)
print(E.add(P, P))              # (6, 3)
print(E.neg(P))                 # (5, 16)
print(E.mul(3, P))              # (10, 6)
print(E.mul(-1, P))             # (5, 16)
print(E.mul(0, P) is O)         # True
print(E.add(P, E.neg(P)) is O)  # True
print(E.mul(19, P) is O)        # True
```

負の座標や `p` 以上の座標も、同じ有限体の元を表す整数として入力できます。

```python
print(E.point(22, -16))  # (5, 1)
```

## 主な操作

| 操作 | 内容 |
| --- | --- |
| `EllipticCurve(A, B, p)` | 係数・素数・非特異性の条件を確認し、曲線を生成する |
| `E.point(x, y)` | 座標を正規化し、曲線上の点を生成する |
| `E.is_on_curve(P)` | `P` が曲線上の点または無限遠点かを判定する |
| `E.normalize_point(P)` | 点の座標を正規化し、曲線上にあることを確認する |
| `E.add(P, Q)` | 点の和 $P+Q$ を計算する |
| `E.neg(P)` | 逆元 $-P$ を計算する |
| `E.mul(n, P)` | 整数倍 $nP$ を計算する。負の整数・0にも対応する |

## 入力の扱い

係数・`p`・座標・整数倍の `n` には整数を指定します。`bool` は受け付けません。

| 例外 | 発生する場合の例 |
| --- | --- |
| `TypeError` | 係数や座標、整数倍の `n` に、整数以外や `bool` を指定した場合 |
| `ValueError` | `p` が5未満または合成数の場合、曲線が特異な場合、曲線上にない点を生成・演算に使う場合 |

`E.is_on_curve(P)` は、整数座標を持つ点が曲線上にない場合には `False` を返します。
`E.is_on_curve(O)` は `True` を返します。

## テストの実行

Pythonの対話モードを使っている場合は `exit()` で終了し、各ファイルを置いたフォルダーで次のコマンドを実行します。

```shell
python -m unittest -v test_elliptic_curve
```

各テストの結果が表示され、最後に `OK` と表示されれば成功です。
現在、32個のテストメソッドで、主に次の内容を確認しています。

- 素数判定、曲線の生成条件、不正な入力の拒否
- 曲線上の点の判定と、係数・座標の正規化
- 通常の加算、点の2倍、逆元との加算、無限遠点との加算
- $y=0$ の点を2倍したときに無限遠点を返すこと
- 固定した期待値との比較による、正・負・0の整数倍の計算
- 小さい曲線での閉性・交換法則・結合法則

閉性・交換法則・結合法則については、次の3曲線で点を全列挙し、全ての点の組合せを確認しています。

| $p$ | $A$ | $B$ |
| --- | --- | --- |
| 5 | 1 | 0 |
| 7 | 0 | 1 |
| 11 | 1 | 6 |

## 実装上の方針と範囲

- 有限体上の除算には、`pow(a, -1, p)` による逆元計算を使います。
- 整数倍は、点の2倍と加算を繰り返す方法（double-and-add）で計算します。
- 素数判定には試し割りを使います。大きい素数では時間がかかるため、小さい素数での学習用計算を想定しています。
- 対象は素体 $`\mathbb{F}_p`$ です。拡大体 $`\mathbb{F}_{p^r}`$（$`r>1`$）上の演算は実装していません。
